# Publicação oficial — `estatutolgbtqia.com.br`

Este repositório existe exclusivamente para publicar o portal do **Estatuto Nacional dos Direitos LGBTQIAPN+** e seu **Dossiê Técnico-Legislativo de 70 páginas** no domínio próprio **`estatutolgbtqia.com.br`** via GitHub Pages (GitHub Actions), preservando intactos os demais domínios da arquitetura (`www.data2comms.com.br` e `acervolula.com.br`).

- **Fonte única do conteúdo:** `rennanmetsi-gif/data2commsfinal` (`estatutolgbtiqia/`)
- **Domínio oficial:** `https://estatutolgbtqia.com.br/`
- **Atualização automática:** a cada push neste repositório, manualmente via *Run workflow*, ou automaticamente a cada 5 minutos acompanhando a branch `main` de `data2commsfinal`.
